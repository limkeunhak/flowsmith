- 노드 서랍: 종류마다 설정 · 입력/출력 보기 · 실행 결과 표시
- 표현식 칸: `{{ $input.x }}` · `$node` · `$params` · `$vars` · `$secrets` · `$item` — 넣을 수 있는 값 고르기

- **버전 비교**: 두 버전(또는 초안)의 바뀐 것을 사람 말로 — 동작 더함 · 뺌 · 바뀜 · 차례 · 노드 · 선 · 입력 · 설정 · 메모(위치만 옮긴 것은 세지 않음)
- JSON으로 가져오기(플로우 목록 화면)

### 녹화 — HTML을 몰라도 동작을 만든다
- 오른쪽 라이브 페이지에서 직접 하면 동작으로 남는다: **녹화 · 읽기 · 둘러보기** 모드
- **녹화가 곧 재생 시험** — 위치 후보를 다시 찾아 «정확히 하나 + 바로 그 요소»인 것만 남기고, 실행기와 같은 방법으로 대신 누른다
- 앞 노드를 재생해 시작 지점까지 가서 녹화 · 이 노드의 동작을 먼저 재생하고 이어서 녹화
- 비밀번호 칸은 값을 받지 않는다 → 시크릿을 고르게 한다 · 금지 버튼은 녹화 중에도 안 눌린다
- 제안: 표의 칸 → **표 전체로** · 되풀이 목록(뉴스 · 검색 결과) → **목록 전체로**(제목 · 링크) · 표의 행 → **행 고르기**(키 칸 · 막을 행) · 떠 있는 안내창 → **있을 때만** · 읽기 → **확인만**(지금 값이 기대값) · 고르기 → 고른 보기의 이름
- 읽기의 이름 · 위치를 **내용으로 짓지 않는다**(내일은 그 글자가 없다) · 해시 클래스를 피한다 · 화면 읽기용 숨은 글자(「새 창 열림」)를 뺀다
- 팝업 창을 따라가 녹화 · 막힌(disabled) 칸도 읽기에서 고른다 · iframe
- **다시 지정** — 깨진 동작 하나만 그 자리까지 재생해 요소를 다시 고른다
- 사람의 크롬에서 녹화(attach) — 쓰는 탭에만 심고 · 크기 안 바꾸고 · 사람이 연 탭은 안 따라가고 · 끝나면 끈다

- **사람 기다리기**(로그인 · 본인 인증): 녹화 중 «🙋 사람 기다리기» → 로그인 화면의 표시 고르기 → 직접 로그인(녹화하지 않음) → 끝났다는 표시. 실행이 멈춰 기다리고, 서버 브라우저면 실제 화면에서 · 사람의 크롬이면 그 창에서 직접 한다
### 웹페이지 동작
주소로 · 누르기(팝업 열기) · 넣기(넣고 다시 읽어 확인) · 고르기 · 체크 · 키 · 기다리기(시간 · 보임 · 사라짐 · 주소 · 네트워크 · 값이 참) · 읽기(알아서 · 값 · 글자 · 체크 · 속성 · 고른 보기 · 링크 주소, 숫자로) · 표/목록 읽기 · 창 닫기 · 행 고르기 · 확인
— 동작마다 «있을 때만» · «조건이 맞을 때만» · 되돌릴 수 없음 · 시간 제한

### 돌리기
- 수동 실행(초안 · 게시된 버전) · 실행 로그(노드마다 단계 · 입력 · 출력 · 실패 카드 — 무엇이 · 어디서 · 왜 · 후보)
- **일정**(cron, 게시된 버전 · 같은 분에 한 번 · 겹치면 건너뜀 기록) · **웹훅**(토큰 · `?wait=1`)
- **다른 플로우가 끝나면**(앞 플로우의 게시된 버전이 성공 · 실패하면 — 실행 입력에 `$input`으로 앞의 결과 · 같은 팀/공용만 · 순환 · 5단 막음 · 못 하면 «실패» 기록) · **파일이 생기면**(공유 폴더의 폴더 · 이름 꼴 · 다 써지면 파일마다 한 번 · 켜기 전 파일은 건너뜀)
- **승인 기다리기** 노드: 안내 · 누가(역할) · 기다리는 시간 → 실행 기록 · 실행 폼 · 대시보드에서 [승인] · [거절](한마디) · 알림 «승인을 기다림» · 받은 값 + 누가 · 한마디를 뒤로 · 거절 · 시간 넘김이면 멈춤 · 점검은 그 앞에서 멈춤 · 워커에서 돌아도 된다
- **다른 플로우 실행** — 행마다 · 동시 1~5 · 멈춤/계속 · 행마다 실행 기록(부른 실행과 이어짐) · 순환 막기
- **실행 화면 보기** — 도는 실행의 실제 화면을 원할 때만(보기만 · 남기지 않음)
- 실행 기록 목록(트리거별)
- **멈추기**(부른 실행까지) · **다시 해 보기**(되돌릴 수 있는 동작만 · 0~5번) · **실행 전체 시간 제한**(기본 60분) · **동시 실행 한도**(차례 기다리기) · **기록 정리**(플로우마다 n개 · n일) · 파일 쓰기의 «n일 지난 파일 지우기»

### 코드 없이 — 비개발자용
- **노드 창(입력 | 설정 | 출력)**: 노드를 누르면 캔버스 위에 세 칸 — 받은 값(표 · JSON · 엑셀) · 설정 · 내놓은 값과 기록 · 실패 카드. **«앞 단계까지 실행»**(이 노드가 받을 값) · **«이 단계까지 실행»**(처음부터 이 노드까지 — 뒤는 돌리지 않음, 되돌릴 수 없는 동작이 있으면 묻는다). Esc · «캔버스로»로 닫는다
- **깨졌을 때 고치는 길**: 실패 카드에 «무엇을 해 주세요»(사이트 탓 · 입력 탓 · 느림을 나눠서)와 단추 — [다시 지정] · [이 위치로 바꾸기](지금 정확히 하나를 가리키는 후보만) · [다시 해 보기 켜기] · [금지 버튼 목록 열기] · [노드 열기]. 실행 기록(알림의 링크)에서도 된다. 알림에는 «고치려면» 한 줄 · 사이트 바뀜 알림의 링크는 변경 감시를 연다(`#/flows/:id/monitor`). 고친 뒤 «다음 할 일»이 «고친 것을 새 버전으로 게시하기»
- **첫 화면 «무엇을 자동화할까요?»**: 템플릿 셋 — 매일 목록 모아 메일로(엑셀 첨부) · 사이트 값 읽어 엑셀로 쌓기 · 모은 목록의 행마다 입력하기. 주소 · 일정(사람 말) · 받는 메일만 물어보고 뼈대를 짠다(웹 동작은 녹화로). id는 자동
- **다음 할 일**: 편집 화면 왼쪽 위 — 녹화 · 목록 고르기 · 받는 메일 · 그 밖의 문제 · 한 번 돌려 보기 · 게시를 차례로. 누르면 그 자리로 · 다 하면 사라짐 · 접기/숨기기
- `{{ $input }}` — 앞 단계가 준 것 전부(읽은 값 여럿을 한 행으로 쌓기)
- **값 칩**: 값 칸에 `{{ $input.title }}` 대신 「뉴스 읽기 › 제목」 · 「실행 입력 › 주문번호」 · 「🔒 shop · 비밀번호」 칩. 글자와 칩을 섞어 쓰고, ×로 빼고, ＋로 끼운다. 닿지 않는 값은 빨간 칩. 표현식 그대로는 「{ }」(고급 보기)
- 동작 문장에도 표현식 대신 사람 말 — 「'주문번호' 칸에 «실행 입력 › 주문번호»를 넣습니다」
- **값 다듬기 노드**: 칸 고르기 · 이름 바꾸기 · 거르기(모두/하나라도 · 1,234원도 숫자로) · 겹치는 행 빼기 · 값 바꾸기 표(보이는 값 가져오기) · 형식(숫자만 · 공백 정리 · 날짜 — 어제 · 3시간 전 · 10.13 · 글자 바꾸기) · 정렬 · 앞 n개 — **마지막 실행의 값으로 바로 미리 보기**
- HTTP JSON 본문을 «이름 – 값 표»로
- **결과를 표로**: 실행 로그의 출력 · 플로우 결과에 목록이 있으면 표(목록이 여럿이면 골라 보기) · JSON으로 바꿔 보기 · **엑셀로 받기**(목록마다 시트)
- **파일을 엑셀로**: 파일 쓰기 노드가 쓴 CSV · JSON Lines · JSON을 «엑셀» 단추로 .xlsx로 받는다(원본은 그대로)
- **메일 알림**: 받는 사람(쉼표로 · 변수) · 성공하면 결과를 엑셀로 붙이기 · 메일 서버가 없으면 화면이 알려 준다
- 노드 고르기에서 커스텀은 «커스텀(코드) — 개발자용»으로 뒤에

### 사내 서버형 — 로그인 · 권한
- **팀 공용 값**: 공용 · 팀마다 변수 · 시크릿(잠김 · 다시 안 보임) — 플로우는 제 팀 → 공용 차례로 찾는다 · 넣고 지우기는 관리자 · 실행 · 점검 · 녹화 · 알림이 같은 길로 푼다
- 로그인(임시 — 메일 + 비밀번호, 로그인 서버는 나중에 잇는다) · 첫 관리자(설정 토큰) · 임시 비밀번호로 들어오면 먼저 바꾸기 · 틀리면 잠시 막기
- 역할: 관리자 · 편집자 · 실행자(게시된 버전만 돌림) · 보는 사람 — 서버가 막고, 화면은 보기 전용으로 바꾼다
- «사람» 화면(관리자): 들이기 · 역할 · 끄기 · 비밀번호 초기화 · 마지막 로그인
- 누가 했나: 실행을 시작한 사람 · 버전을 만든 사람 · 초안을 고친 사람
- **팀**(관리자가 만들고 사람을 넣는다): 내 팀 플로우와 공용만 보인다 · 만들 때 둘 팀 고르기 · 플로우 설정에서 팀 옮기기 · 목록에 팀 표시 · 다른 팀 플로우 부르기 · 파일 읽기는 막는다
- 밖으로 열면 로그인이 저절로 켜진다 · https · 커스텀 코드 끄기 · HTTP 주소 지킴이

### 워커 — 서버 · 사람 PC (젠킨스의 노드처럼)
- **standalone 그대로** — 워커를 붙이지 않으면 서버 혼자 돈다
- «워커» 화면: 서버(내장) 줄 · 워커마다 연결 상태(연결됨 · 꺼짐 · 잠시 끔 · 마지막 연결) · 라벨 · 동시 실행 수 · 지금 도는 실행(누르면 그 실행 기록) · 기다리는 수 · 그 PC(이름 · node · 확장) · 이 워커에서 도는 플로우 수
- 관리자: 워커 더하기(토큰과 PC에서 켤 명령 — Windows · macOS/Linux — 이때 한 번) · 이름 · 라벨 · 동시 실행 수 · 잠시 끄기 · 새 토큰(옛 연결은 끊김) · 지우기(도는 플로우가 있으면 막음) · 팀 전용
- 플로우 설정 «어디서 돌리나»: 서버 · 워커 하나 · 라벨(그 라벨의 비어 있는 워커) — 일정 · 웹훅 · 점검도 그곳에서 · attach 플로우면 «그 크롬이 있는 PC의 워커를 고르세요»
- 실행 단추에서 **이번만 어디서** · 실행 기록에 «어디서 돌았나»
- 워커가 꺼져 있으면 기다리지 않고 바로 실패(«그 PC에서 워커 프로그램을 켜세요») · 돌던 중 끊기면 «연결이 끊김» · 자리가 차면 줄을 서고 줄에서도 멈출 수 있다
- 워커에서 돌아도 **파일은 서버에** 남는다 · 다른 플로우 실행도 된다 · 시크릿이 오가니 https 서버에만 붙는다
- **녹화도 그 PC에서**(사람의 크롬에 붙는 플로우): «녹화 시작»에서 «어느 PC의 크롬에서»를 고른다(이 브라우저가 기억) · 사람은 자기 크롬 창에서 직접 해도 Studio에 녹화된다 · 잠시 끈 워커도 녹화는 된다(녹화 전용 PC) · 워커 화면에 «녹화 중»

### 다른 시스템과 — HTTP 요청 · 알림
- **HTTP 요청 노드**: 방법 · 주소 · 쿼리 · 헤더(시크릿 — `Bearer {{ $secrets.apiKey }}`) · 본문(JSON은 글자 값 안에서 채움 · 값 하나면 값 그대로 · 폼 · 글자) · 받은 본문(알아서/JSON/글자 · 5MB까지) · 4xx/5xx면 실패 또는 그대로 넘김 · 시간 제한 · 다시 해 보기(GET · HEAD만) · 점검은 POST 앞에서 멈춤
- **알림**: 실패 · 회복 · 성공 · 멈춤 · 사이트가 바뀜 → Slack · Teams · 웹훅(JSON) · 이어지는 실패는 처음만 · 주소는 시크릿으로 · 시험 보내기 · 보낸 기록(주소 없이) · 링크로 그 실행 기록 바로 열기 · ★게시된 버전만

### 파일
- **파일 쓰기**: CSV(머리줄 · 엑셀 한글 BOM · 열 순서) · JSON Lines · JSON · 텍스트 · 이어 붙이기/덮어쓰기 · 롤링(시 · 일 · 월 · 실행마다 · 행 수 · 크기) · 이미 저장한 것 건너뛰기 · 수집 시각
- **파일 읽기**: 다른 플로우의 폴더 · 공유 폴더 · 이 플로우 폴더 · 가장 최근/오늘 · 어제 · n 전/이름 그대로 · «파일 쓰기 노드에서 가져오기»
- 플로우마다 uuid 폴더(복사해도 섞이지 않음) · 공유 폴더 · 저장된 파일 미리 보기 · 내려받기 · 지우기

### 사이트가 바뀌면 — 변경 감시
- 주기 점검(게시된 버전 · 되돌릴 수 없는 동작 앞에서 멈춤) · 요소 지문 비교(ok · changed · broken)
- 실제 실행이 «요소 없음»으로 멈추면 확인 점검 → 정말 깨졌을 때만 알린다
- 캔버스 · 동작에 «바뀜 · 없음» 표시 · 발견 카드에서 [다시 지정]

### 보안 프로그램 사이트 · 확장
- **사람의 브라우저에 붙기**(CDP) — 실행 · 녹화 · 사람이 연 탭에서 시작 · 사람의 탭은 닫지 않는다
- 확장 노드 — 사내 코드 모듈을 그대로 부르는 노드(개인정보라 한 출력은 가림)
- 같은 일을 녹화 · 편집으로 직접 만드는 길 — [RECORDING.md](RECORDING.md)
