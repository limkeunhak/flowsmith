# 파일

**파일 쓰기** 노드가 저장한 파일은 서버에 남습니다. 워커에서 실행해도 마찬가지입니다.

## 어디에

| 폴더 | 뜻 |
|---|---|
| 이 워크플로우 폴더 | 이 워크플로우만 쓰는 곳 |
| 공유 폴더 | 모든 워크플로우가 함께 쓰는 곳 |
| 다른 워크플로우의 폴더 | 파일 읽기로만. 같은 팀이거나 공용 워크플로우여야 합니다 |

## 형식 · 나누기

- 형식: **CSV**(엑셀이 엽니다) · JSONL · JSON · 글
- 이어 붙이기 · 덮어쓰기 · 겹치는 행 건너뛰기(키 칸)
- 시각별(한 시간 · 하루 · 한 달) · 번호별(실행마다 · 행 수 · 크기)로 파일을 나눕니다
- n일 지난 파일 지우기

## 저장된 파일 보기

워크플로우 편집 화면에서 저장된 파일을 미리 보고, 내려받고, 지울 수 있습니다. CSV는 **엑셀로** 내려받을 수 있습니다.
