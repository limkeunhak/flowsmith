# 알림

종 아이콘(🔔)에서 **언제**와 **어디로**를 고릅니다. 알림은 **게시된 버전**의 실행에만 보냅니다.

## 언제

| 때 | 뜻 |
|---|---|
| 실패 | 실행이 실패했을 때. 실패가 이어지면 처음 한 번만 보냅니다 |
| 다시 성공(회복) | 실패한 뒤 처음 성공했을 때 |
| 성공 | 성공할 때마다 |
| 멈춤 | 사람이 멈췄을 때 |
| 막힘(고르면 안 되는 건) | 고르면 안 되는 행에 걸려 막힘 갈래로 끝났을 때 |
| 사이트가 바뀜 | 변경 감시가 화면이 바뀐 것을 찾았을 때 |
| 사람을 기다림 | 실행이 로그인 등을 기다리기 시작했을 때(끝나기 전에 옵니다) — 링크로 그 실행을 열어 직접 하세요 |
| 승인을 기다림 | 실행이 «승인 기다리기» 노드에 닿았을 때 — 링크로 그 실행을 열어 [승인] · [거절]을 누르세요 |

## 어디로

- **Slack · Teams** — 채널의 수신 웹훅 주소를 넣습니다
- **웹훅** — 받는 시스템의 주소
- **메일** — 받는 사람 메일(쉼표로 여럿). 결과 표를 엑셀로 붙일 수 있습니다

**시험 보내기**로 미리 확인할 수 있습니다(저장한 뒤).

## 알림에 담기는 것

워크플로우 이름 · 결과 · 실패한 노드와 까닭 · **고치려면** 안내 · 그 실행 기록으로 가는 링크.
