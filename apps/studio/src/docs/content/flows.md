# 워크플로우 만들기

워크플로우는 **노드**(한 단계)를 **선**으로 이은 것입니다. 앞 노드가 내놓은 값이 다음 노드로 넘어갑니다.

## 노드 더하기 · 잇기

- 캔버스 가운데의 **＋** 또는 노드 오른쪽의 **＋**를 누르면 노드 고르기가 열립니다.
- 노드를 두 번 누르면 노드 창이 열립니다. 왼쪽은 **입력**, 가운데는 **설정**, 오른쪽은 **출력**입니다.
- 노드의 오른쪽 점을 끌어 다른 노드에 놓으면 이어집니다.

## 노드 지우기

- 노드에 마우스를 올리면 위에 작은 막대가 뜹니다. **🗑**를 누르면 지워집니다(⚙는 설정 열기).
- 노드를 **오른쪽 클릭**해 «노드 지우기»를 골라도 됩니다. 노드 창 위쪽의 **지우기** 단추도 같습니다.
- 지우면 아래에 **«되돌리기»**가 잠깐 뜹니다 — 누르면 노드와 이어진 선이 그대로 돌아옵니다.
- 선만 끊으려면 선에 마우스를 올려 🗑를 누릅니다.

## 메모

캔버스 오른쪽 위의 **메모** 단추로 설명 상자를 놓습니다. 위 띠를 잡아 옮기고, 고르면 크기 · 색을 바꾸거나 지웁니다. 실행과는 상관없고, 워크플로우를 처음 보는 사람이 읽기 좋게 남겨 두는 자리입니다.

## 실행 입력

워크플로우 설정의 **실행 입력**은 돌릴 때마다 받는 값입니다. 종류를 정하면 돌리기 전에 맞는지 봅니다.

| 종류 | 받는 값 |
|---|---|
| 글자 | 무엇이든 |
| 숫자 | `1,234.5`처럼(쉼표 허용) |
| 날짜 | `2026-10-18` — 실행 창 · 실행 폼에는 달력이 뜹니다 |
| 고르기 | 정해 둔 보기 중 하나 |

**기본값**을 두면 비워 두고 돌려도 그 값을 씁니다(일정 · 웹훅에도). **설명**은 실행 창과 실행 폼에서 칸 아래에 보입니다.

## 저장 · 버전 · 게시

| 상태 | 뜻 |
|---|---|
| 초안 | 지금 고치고 있는 것. 문제가 있어도 저장됩니다 |
| 버전 | 초안을 굳힌 것. 문제가 없어야 만들 수 있습니다 |
| 게시 | 일정 · 웹훅 · 다른 워크플로우가 실행하는 버전 |

**게시**를 누르면 지금 초안으로 새 버전을 만들어 바로 게시합니다. 게시한 뒤에 고친 것은 다시 게시해야 운영에 반영됩니다.

게시 단추 옆 메뉴의 **바뀐 것 보기**는 두 버전(또는 초안)이 무엇이 다른지 사람 말로 보여 줍니다 — 「동작 3 «'조회' 버튼을 누릅니다»를 더했습니다」 · 「노드 «정리» 설정이 바뀌었습니다 — 코드」. 캔버스 위치만 옮긴 것은 세지 않습니다. 게시하기 전에 한 번 보세요.

## 문제 목록

위쪽의 **문제** 표시를 누르면 고칠 것이 보입니다. 항목을 누르면 그 노드가 열립니다.

- «누를 곳을 아직 고르지 않았습니다» — 녹화하거나 **요소 고르기**로 고르세요.
- «주소가 비었습니다» — `https://`로 시작하는 주소를 넣으세요.

## 다음 할 일

캔버스 왼쪽 위의 **다음 할 일**이 남은 일을 차례로 알려 줍니다. 녹화 → 한 번 실행 → 게시 순서입니다.

## 워크플로우 설정

톱니바퀴(⚙)에서 엽니다.

- **실행 입력** — 실행할 때마다 받는 값(예: 주문번호)
- **변수** — 이 워크플로우에서만 쓰는 고정 값(예: 사이트 주소)
- **팀 공용 변수** — 여러 워크플로우가 함께 쓰는 값. 관리자가 «팀» 화면에 넣은 것 중 골라 `{{ $vars.이름 }}`으로 씁니다
- **시크릿** — 로그인 정보처럼 숨길 값. 한 번 넣으면 다시 보이지 않습니다. **팀 공용 값 쓰기**를 켜면 «팀» 화면의 같은 이름 값을 씁니다(계정이 바뀌면 한 곳만 고칩니다)
- **금지 버튼** — 이 글자가 들어간 버튼은 누르지 않습니다
- **실행 위치** — 서버 또는 [워커](#/docs/workers)
- **팀** — 이 워크플로우를 볼 수 있는 팀
