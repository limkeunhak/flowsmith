# 시작하기

Flowsmith는 웹 사이트에서 반복하는 일을 자동으로 해 주는 도구입니다. 사람이 한 번 해 보이면 그 동작이 **워크플로우**로 남고, 정한 때마다 그대로 실행됩니다. 코드를 몰라도 됩니다.

## 이런 일에 씁니다

- 매일 아침 여러 사이트에서 값을 읽어 엑셀로 모으기
- 목록 파일의 행마다 다른 사이트에 입력하기
- 사이트의 상태가 바뀌면 메신저로 알림 받기

## 5분 만에 첫 워크플로우

1. 위 메뉴의 **워크플로우**에서 템플릿을 고르거나 **빈 워크플로우**를 누릅니다. 빈 워크플로우는 바로 캔버스가 열리고 이름을 묻습니다(그만두면 지워집니다).
2. 캔버스의 **웹페이지** 노드를 열고 시작 주소를 넣습니다.
3. **녹화로 동작 더하기**를 눌러 사이트에서 평소처럼 누르고 입력합니다. 한 동작마다 기록됩니다.
4. 아래 **워크플로우 실행**으로 한 번 돌려 봅니다. 노드마다 성공 · 실패가 표시됩니다.
5. 위의 **게시**를 누르면 그 버전이 일정 · 웹훅으로 실행되는 «운영 버전»이 됩니다.

> 녹화 중에 누르는 것은 실제 사이트에서 실제로 일어납니다. 결제 · 발행처럼 되돌릴 수 없는 버튼은 워크플로우 설정의 **금지 버튼**에 넣어 두세요.

## 화면 둘러보기

| 메뉴 | 하는 일 |
|---|---|
| 워크플로우 | 내 워크플로우 목록 · 새로 만들기 — **화면**(워크플로우가 여는 주소)으로 알아서 묶어 접고 폅니다. **화면 규칙**에 주소 앞부분과 이름(예: `shop.example/orders` → 주문)을 한 번 적어 두면 새 워크플로우도 제자리에 들어갑니다. 틀린 것만 줄을 골라 **화면 직접 지정**. **묶어 보기**로 Suite별로도 봅니다 |
| 템플릿 | 하고 싶은 일을 고르면 뼈대를 짜 드립니다 |
| 대시보드 | 실행 수 · 실패율 · 오류를 한눈에 |
| 워커 | 워크플로우를 실행할 PC 관리 |
| 사람 · 팀 | 사람과 권한(관리자) |
| 가이드 | 이 문서 |
