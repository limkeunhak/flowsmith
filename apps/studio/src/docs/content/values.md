# 값 연결하기

앞 단계의 값을 다음 단계에 쓰려면 **값 칩**을 고릅니다. 입력 칸 옆의 **＋**를 누르면 쓸 수 있는 값이 목록으로 나옵니다.

## 값 칩 안쪽

값 칩은 `{{ }}`로 저장됩니다. 직접 써도 됩니다.

| 쓰는 법 | 뜻 |
|---|---|
| `{{ $input.주문번호 }}` | 바로 앞 노드가 내놓은 값 |
| `{{ $input }}` | 앞 노드가 내놓은 것 전부 |
| `{{ $node.login.userName }}` | 특정 노드(id: login)가 내놓은 값 |
| `{{ $params.orderNo }}` | 실행할 때 받은 실행 입력 |
| `{{ $vars.baseUrl }}` | 워크플로우 설정의 변수 |
| `{{ $secrets.portal.password }}` | 시크릿(로그인 정보) |
| `{{ $item.주문번호 }}` | «다른 워크플로우 실행»이 행마다 돌 때 그 행 |

## 글과 섞어 쓰기

`{{ $vars.baseUrl }}/orders/{{ $params.orderNo }}` 처럼 글자 사이에 넣을 수 있습니다.

> 시크릿은 입력 · 헤더 같은 정해진 자리에만 쓸 수 있고, 실행 기록에는 가려져 남습니다.
