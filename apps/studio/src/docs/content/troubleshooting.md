# 문제 해결

## 요소를 찾지 못했습니다

사이트 화면이 바뀐 경우가 많습니다. 실패 카드의 **다시 지정**을 누르고 같은 요소를 한 번 누르세요. 고친 뒤에는 **게시**해야 운영에 반영됩니다.

## 같은 요소가 여러 개입니다

비슷한 버튼이 여럿인 화면입니다. **다시 지정**으로 고르면 더 정확한 위치를 찾습니다. 표 안이라면 **행 고르기**를 쓰세요.

## 로그인이 풀렸습니다

사람의 크롬에 붙는 워크플로우라면 그 PC의 크롬에서 다시 로그인하세요. 시크릿으로 로그인하는 워크플로우라면 워크플로우 설정 › 시크릿의 값을 확인하세요.

## 워커가 연결돼 있지 않습니다

그 PC에서 워커 프로그램이 켜져 있는지 확인하세요. «토큰이 맞지 않습니다»가 보이면 관리자에게 새 토큰을 받으세요.

## 실행이 시작되지 않습니다

- «배포된 버전이 없습니다» — **게시**를 먼저 하세요
- «실행 입력 '…'가 없습니다» — 실행 단추의 ▲에서 실행 입력을 채우세요
- «시크릿 '…'의 값이 저장되지 않았습니다» — 워크플로우 설정 › 시크릿에 값을 넣으세요

## 시간 제한을 넘었습니다

사이트가 느리거나 기다리는 요소가 나타나지 않은 경우입니다. 그 동작의 시간 제한을 늘리거나, 앞에 **기다리기** 동작을 넣으세요.

## 더 도움이 필요하면

관리자에게 실행 기록의 링크를 보내 주세요. 그 실행의 노드마다 입력 · 출력 · 까닭이 남아 있습니다.
