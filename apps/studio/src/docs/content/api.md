# API

스크립트나 다른 시스템에서 Flowsmith를 조회하고 제어합니다. 워크플로우 실행 · 실행 기록 · 워커 · 대시보드를 화면 없이 다룰 수 있습니다.

## API 목록 보기

위 막대 오른쪽의 **API**를 누르면 모든 API가 무리별로 보입니다. 하나를 펼치면 필요한 역할 · 입력 · 응답이 나옵니다.

- **Try it out** › **Execute**를 누르면 지금 로그인한 그대로 바로 불러 봅니다
- 위의 **OpenAPI JSON**은 명세 파일입니다. Postman 같은 도구에 넣어 쓸 수 있습니다

## 토큰 만들기

로그인을 켠 서버에서는 밖에서 부를 때 **API 토큰**이 필요합니다.

1. **API** › **내 토큰** › **토큰 만들기**
2. 이름(어디에 쓰는지) · 역할 · 사용 기간을 고릅니다
3. 토큰은 **한 번만** 표시됩니다. 바로 복사해 두세요

```
curl -H "Authorization: Bearer fsa_…" https://<서버 주소>/api/flows
```

| 정하는 것 | 뜻 |
|---|---|
| 역할 | 내 역할 이하만 고를 수 있습니다. 내 역할이 낮아지면 토큰도 따라 낮아집니다 |
| 사용 기간 | 30일 · 90일 · 1년 · 끝나지 않음 |

## 자주 쓰는 API

| 하는 일 | 부르는 법 |
|---|---|
| 워크플로우 목록 | `GET /api/flows` — 묶음(`group`) · 설명 첫 줄(`description`)도 함께 |
| 묶음 옮기기 | `PUT /api/flow-group` — 본문 `{ "ids": ["…"], "group": "주문" }`(묶음 없음은 `null`) |
| 게시된 버전 받기 | `GET /api/flows/<id>/published` — 받아 둔 것이 있으면 `If-None-Match`로 보내 안 바뀌었을 때 304 |
| 게시된 버전 실행 | `POST /api/flows/<id>/runs` — 본문 `{ "params": { … } }` |
| 실행 결과 | `GET /api/runs/<runId>` |
| 실행 멈추기 | `POST /api/runs/<runId>/cancel` |
| 워커 상태 | `GET /api/workers` |
| 대시보드 숫자 | `GET /api/dashboard?days=7` |

실행은 바로 `runId`를 돌려주고 뒤에서 돕니다. 끝났는지는 실행 결과를 다시 물어보세요.

## 알아 둘 것

- 토큰으로 한 일은 만든 사람의 이름으로 기록됩니다
- 토큰으로는 새 토큰을 만들거나 비밀번호를 바꿀 수 없습니다
- 사람을 끄거나 토큰을 지우면 그 순간부터 쓸 수 없습니다
- 남의 팀 워크플로우는 토큰으로도 보이지 않습니다
- 오류는 언제나 `{ "error": "…", "problems": [ … ] }` 모양입니다
- 로그인을 끈 서버(이 PC에서만 쓸 때)는 토큰 없이 부릅니다
