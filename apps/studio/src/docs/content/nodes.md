# 노드 종류

## 웹에서

| 노드 | 하는 일 |
|---|---|
| 웹페이지 | 사이트를 열고 누르기 · 입력 · 읽기를 합니다. 녹화로 만듭니다 |
| 사람 기다리기 | 로그인 · 본인 인증처럼 사람이 할 일을 기다렸다가 같은 페이지에서 이어 갑니다. 캔버스에 주황 점선 · 사람 아이콘으로 보입니다(속은 사람 기다리기 동작 하나만 든 웹페이지 노드) |

### 웹페이지 노드 나누기

한 노드에 단계가 많으면 캔버스에서 흐름이 안 보입니다. **«페이지 접속» → «사람 기다리기» → «주문 읽기»**처럼 나눌 수 있습니다.

- **단계별로 나누기** — 노드를 오른쪽 클릭하거나 노드 창 위쪽 단추. 사람 기다리기마다 앞뒤를 잘라 «페이지 접속 → 사람 기다리기 → 그 뒤 동작»으로 나눕니다. 잘못 나눴으면 알림의 **되돌리기**.
- **여기서 나누기** — 노드 창의 동작을 펼치면 보입니다. 그 동작부터 다음 노드로 갑니다.
- **녹화할 때** — «🙋 사람 기다리기는 따로 노드로 나누기»가 켜져 있으면 저절로 나뉩니다. 동작마다 **✂**를 누르면 그 자리에서도 나뉩니다.
- 나눈 노드들은 **«앞 페이지에서 이어서»** 같은 브라우저 페이지에서 이어 돕니다. **앞 노드에서 읽은 값도 함께 넘어가서** 뒤 노드가 그대로 씁니다 — 나누기 전과 결과가 같습니다.
- 주소만 열고 동작이 없는 **«페이지 접속»** 노드를 둘 수 있습니다(주소로 시작할 때만).
- ☆실패한 뒤 «이어서 돌리기»로 나눈 노드의 가운데부터 다시 할 수는 없습니다 — 브라우저 페이지가 이미 닫혔습니다. 처음부터 다시 돌리세요.

## 값과 파일

| 노드 | 하는 일 |
|---|---|
| 값 다듬기 | 목록의 칸 고르기 · 거르기 · 겹친 것 빼기 · 값 바꾸기 · 모양 바꾸기 · 정렬 · 앞에서 몇 개 |
| 파일 쓰기 | 값을 CSV · JSON · 글 파일로 저장합니다. 날짜별 · 번호별로 나눌 수 있습니다 |
| 파일 읽기 | 저장해 둔 파일을 읽어 목록으로 내놓습니다 |

## 흐름

| 노드 | 하는 일 |
|---|---|
| 조건 | 값을 견주어 갈래를 나눕니다(같다 · 포함 · 비었다 …) |
| 다른 워크플로우 실행 | 다른 워크플로우를 한 번, 또는 목록의 행마다 실행합니다 |
| 검사 | 앞 노드의 값이 기대대로인지 봅니다(같다 · 포함 · 숫자 크기 · 행 수 …). 하나라도 틀리면 «불통과» — [테스트](#/docs/tests) |
| 승인 기다리기 | 제출 · 저장 · 발송처럼 되돌릴 수 없는 일 앞에서 사람이 승인해야 이어 갑니다. 누가(역할) · 얼마나 기다릴지 정합니다 — 거절하면 멈춥니다 |

## 다른 시스템

| 노드 | 하는 일 |
|---|---|
| HTTP 요청 | API를 부릅니다. 결과 JSON을 표로 볼 수 있습니다 |
| 확장 | 설치된 확장 기능을 부릅니다(예: 사내 주문 시스템 넣기) |

## 고급

| 노드 | 하는 일 |
|---|---|
| 커스텀 | 직접 쓴 코드를 실행합니다. 관리자가 끌 수 있습니다 |

## 출력 고정

뒤 노드(값 다듬기 · 파일 · HTTP)를 만드는 동안 포털을 매번 다시 돌지 않으려면, 노드 창 **출력** 칸의 **📌 이 출력 고정**을 누르세요. 그 뒤 **초안 시험**에서 그 노드는 돌지 않고 고정한 값을 내놓습니다. 캔버스 타일에 📌가 붙습니다.

- 게시된 버전 · 일정 · 웹훅은 늘 진짜로 돕니다
- 고정한 값은 버전에 들어가지 않습니다
- 웹페이지 노드를 고정하면 페이지도 열리지 않으니, «앞 페이지에서 이어서» 시작하는 뒤 웹페이지 노드는 멈춥니다
- 다 만들었으면 **고정 풀기**

## 노드 창

노드를 두 번 누르면 열립니다.

- **입력** — 앞 노드가 넘겨준 값
- **설정** — 이 노드가 할 일
- **출력** — 이 노드가 내놓은 값. **이 단계까지 실행**으로 바로 확인할 수 있습니다
