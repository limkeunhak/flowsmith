# 실행 기록 · 감시

## 실행 기록

편집 화면 위쪽의 **실행 기록**에서 지난 실행을 봅니다. 결과로 거르고, 날짜별로 묶어 보여 줍니다. 실행을 누르면 그때의 캔버스와 노드마다의 입력 · 출력이 보입니다.

실패한 실행에는 **무엇이 · 어디서 · 왜**와 **고치는 단추**가 함께 나옵니다.

## 변경 감시

사이트 화면이 바뀌면 녹화한 동작이 깨질 수 있습니다. **감시**는 게시된 워크플로우를 주기적으로 **점검 실행**합니다.

- 점검 실행은 되돌릴 수 없는 동작 앞에서 멈추고, 요소가 녹화 때와 같은지만 봅니다
- 결과: **정상 · 바뀜 · 깨짐 · 못 함**
- 실제 실행이 요소를 못 찾았을 때도 확인 점검을 돌립니다
- 점검에 쓸 입력값은 워크플로우 설정의 **점검용 입력값**에 넣습니다

## 대시보드

왼쪽 **대시보드**에서 기간(오늘 · 7 · 30 · 90일)과 워크플로우를 골라 봅니다.

- 실행 수 · 실패율 · 노드 실패율 · 실행 시간(P95)
- 날마다 실행 · 날마다 실행 시간
- 노드 종류 · 워크플로우 · 실행 위치별 나눔
- 최근 오류 · 최근 실행 — 누르면 그 실행 기록으로 갑니다

> 실패율은 끝난 실행(성공 + 실패) 중 실패의 비율입니다. 사람이 멈춘 실행은 넣지 않습니다.

## 기록 보관

실행 기록은 워크플로우마다 최근 500개, 90일까지 남깁니다(서버 설정으로 바꿀 수 있습니다).
