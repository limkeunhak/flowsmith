# 데스크톱 앱

Flowsmith 데스크톱 앱(Windows · macOS)은 처음 켤 때 둘 중 하나로 씁니다. 나중에 **내 설정 › 데스크톱 앱 › 연결 바꾸기**에서 바꿉니다.

> **처음 설치할 때 한 번** — 앱에 인증서 서명이 없어 운영체제가 막습니다.
> Windows: «Windows의 PC 보호»에서 **추가 정보 › 실행**.
> macOS: dmg에서 Flowsmith를 «응용 프로그램»으로 끈 뒤, 열면 막히면 **시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기**(또는 터미널에서 `xattr -cr /Applications/Flowsmith.app`).
> 새 버전은 저절로 오지 않습니다 — 새 설치 파일을 받아 다시 까세요(데이터는 그대로입니다).

| | 이 PC에서만 | 회사 서버에 붙기 |
|---|---|---|
| 워크플로우 · 실행 기록 | 이 PC에 | 회사 서버에 |
| 편집 화면 | 이 PC의 서버 | 회사 서버의 편집 화면을 앱 창에 · 로그인은 회사 계정 |
| 실행 | 이 PC에서 | 기본은 워크플로우 설정대로(공용 워커 · 서버) · **내 PC에서 실행하기**를 켜면 이 PC에서 |
| 필요한 것 | 없음 | 서버 주소 · 관리자에게 받은 **워커 토큰**(이 PC에 한 번만) |

## 회사 서버에 붙기

1. 관리자에게 이 PC의 **워커 토큰**을 받습니다(관리자가 «워커» 화면에서 **개인 워커**로 만듭니다).
2. 앱 첫 화면에서 **회사 서버에 붙기**를 고르고 서버 주소(https://…)와 토큰을 넣습니다. 토큰은 이 PC에 잠가 두고(Windows 사용자 암호화) 다음부터는 묻지 않습니다.
3. 회사 계정으로 로그인합니다.
4. 실행 단추 왼쪽의 **내 PC에서 실행하기**를 켜고 돌리면 이 PC에서 돕니다 — «띄우기» 워크플로우도 실행 창에 떠서 눈으로 봅니다. 끄면 워크플로우 설정대로(공용 워커 · 서버) 돕니다.

- 이 PC(개인 워커)는 **내가 «내 PC에서»로 돌린 실행만** 받습니다. 다른 사람이 돌린 실행이나 일정 · 웹훅은 오지 않습니다.
- 앱 안 브라우저 · 지갑 브라우저 워크플로우는 화면이 있어야 해서 늘 내 PC에서 돕니다(칸이 켜진 채 잠겨 있습니다).
- 녹화도 내 PC에서 합니다 — 라이브 패널 자리에 진짜 페이지가 뜹니다. «녹화할 곳»에서 서버를 고를 수도 있습니다.
- 토큰이 거절되면(관리자가 새로 만들었거나 지웠을 때) 앱이 첫 화면을 다시 엽니다 — 새 토큰을 받아 넣으세요.

## 앱 안 브라우저

앱에서는 브라우저를 하나 더 고를 수 있습니다.

| 브라우저 | 어디서 | 언제 |
|---|---|---|
| **띄우기**(기본) | 서버 · 워커가 띄우는 브라우저(창 없음) | 어디서나 — 서버 · 다른 워커에서도 돕니다 |
| **앱 안 브라우저** | 데스크톱 앱 창 안 | 녹화할 때 페이지를 바로 누르고 치고 싶을 때 · 실행을 눈으로 지켜보거나 사람이 거들 때 |
| **지갑 브라우저(MetaMask)** | MetaMask를 실은 크롬 창 | MetaMask 확장으로 로그인하는 사이트 — [블록체인 사이트](#/docs/wallet) |
| **사람의 크롬에 붙기** | 사람이 로그인해 둔 크롬 | 보안 프로그램 · OTP 사이트 |

## 쓰는 법

1. 워크플로우 설정 › **브라우저**에서 **앱 안 브라우저**를 고릅니다.
2. 웹페이지 노드에서 **녹화로 동작 더하기**를 누르면, 오른쪽 라이브 패널 자리에 진짜 페이지가 뜹니다. 화면 그림이 아니라 페이지 그 자체라 스크롤 · 글자 입력(한글 포함) · 끌기가 그대로 됩니다.
3. **실행**하면 페이지가 따로 창(«Flowsmith 실행 — 워크플로우 이름»)에 뜹니다. 앞으로 나오지 않고 뒤에서 돌다가, **사람 기다리기**에 이르면 그 창이 앞으로 나옵니다 — 그 창에서 직접 하세요. 실행이 끝나면 창은 저절로 닫힙니다.
4. 편집 화면의 **실제 화면 보기**로도 같은 화면을 볼 수 있습니다.

## 알아 둘 것

- **실행마다 새 세션**입니다 — 쿠키 · 로그인이 실행 사이에 이어지지 않습니다(띄우기와 같습니다). 로그인은 시크릿으로 넣거나 «사람 기다리기»로 합니다.
- **데스크톱 앱에서만 돕니다.** 사내 서버 · 다른 워커로 보내면 기다리지 않고 «앱 안 브라우저를 열 수 없습니다»로 바로 실패합니다. 어디서나 돌려야 하면 브라우저를 **띄우기**로 바꾸세요 — 녹화한 동작은 그대로 씁니다.
- 녹화 중에 편집 화면의 덮개(진행 표시 · 고르기 목록 · 대화상자)가 떠야 할 때는 페이지가 잠깐 숨습니다.
- 라이브 패널이 좁으면 사이트가 휴대폰 배치가 되지 않게 페이지를 조금 줄여 보입니다.
- 테스트 지갑(페이지에 넣는 지갑)은 앱 안 브라우저에 싣지 않습니다.
