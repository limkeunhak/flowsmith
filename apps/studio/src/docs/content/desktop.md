# 데스크톱 앱 — 앱 안 브라우저

Flowsmith 데스크톱 앱(Windows)은 편집 화면 · 서버 · 워커를 이 PC에서 함께 켭니다. 앱에서는 브라우저를 하나 더 고를 수 있습니다.

| 브라우저 | 어디서 | 언제 |
|---|---|---|
| **띄우기**(기본) | 서버 · 워커가 띄우는 브라우저(창 없음) | 어디서나 — 서버 · 다른 워커에서도 돕니다 |
| **앱 안 브라우저** | 데스크톱 앱 창 안 | 녹화할 때 페이지를 바로 누르고 치고 싶을 때 · 실행을 눈으로 지켜보거나 사람이 거들 때 |
| **지갑 브라우저(MetaMask)** | MetaMask를 실은 크롬 창 | MetaMask 확장으로 로그인하는 사이트 — [블록체인 사이트](#/docs/wallet) |
| **사람의 크롬에 붙기** | 사람이 로그인해 둔 크롬 | 보안 프로그램 · OTP 사이트 |

## 쓰는 법

1. 워크플로우 설정 › **브라우저**에서 **앱 안 브라우저**를 고릅니다.
2. 웹페이지 노드에서 **녹화로 동작 더하기**를 누르면, 오른쪽 라이브 패널 자리에 진짜 페이지가 뜹니다. 화면 그림이 아니라 페이지 그 자체라 스크롤 · 글자 입력(한글 포함) · 끌기가 그대로 됩니다.
3. **실행**하면 페이지가 따로 창(«Flowsmith 실행 — 워크플로우 이름»)에 뜹니다. 앞으로 나오지 않고 뒤에서 돌다가, **사람 기다리기**에 이르면 그 창이 앞으로 나옵니다 — 그 창에서 직접 하세요. 실행이 끝나면 창은 저절로 닫힙니다.
4. 편집 화면의 **실제 화면 보기**로도 같은 화면을 볼 수 있습니다.

## 알아 둘 것

- **실행마다 새 세션**입니다 — 쿠키 · 로그인이 실행 사이에 이어지지 않습니다(띄우기와 같습니다). 로그인은 시크릿으로 넣거나 «사람 기다리기»로 합니다.
- **데스크톱 앱에서만 돕니다.** 사내 서버 · 다른 워커로 보내면 기다리지 않고 «앱 안 브라우저를 열 수 없습니다»로 바로 실패합니다. 어디서나 돌려야 하면 브라우저를 **띄우기**로 바꾸세요 — 녹화한 동작은 그대로 씁니다.
- 녹화 중에 편집 화면의 덮개(진행 표시 · 고르기 목록 · 대화상자)가 떠야 할 때는 페이지가 잠깐 숨습니다.
- 라이브 패널이 좁으면 사이트가 휴대폰 배치가 되지 않게 페이지를 조금 줄여 보입니다.
- 테스트 지갑(페이지에 넣는 지갑)은 앱 안 브라우저에 싣지 않습니다.
