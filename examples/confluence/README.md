# Confluence — 페이지 트리를 PDF로

`confluence-pdf.json` — 사내 Confluence(Data Center)에서 시작 페이지와 그 아래 모든 페이지를 **Confluence의 PDF 내보내기**로 받아, 트리 경로대로 폴더에 저장한다.

```
로그인(사람) → 페이지 목록(REST) → 목록 CSV → 페이지마다 PDF(행마다 반복 · 파일로 저장) → 결과 CSV → 판정
```

| 노드 | 하는 일 |
|---|---|
| 로그인(사람) | 로그인 화면을 열고 **사람이 로그인할 때까지** 기다린다(10분). 실행 화면에서 직접 로그인한다 — 비밀번호는 워크플로우에 두지 않는다 |
| 페이지 목록(REST) | 로그인한 브라우저의 쿠키로 시작 페이지를 찾고 `/child/page`를 재귀로 돈다. 좌측 트리를 화면에서 펼치지 않는다 — 접힌 가지 · 늦게 그려지는 트리를 놓치지 않게. 찾기는 차례로: 제목 그대로(페이지) → 제목 그대로(종류 무관) → 글자 검색 → **트리를 이름으로 내려가기**(맨 앞 이름부터 하위 페이지에서 다음 이름). 제목은 전각 괄호 · 공백 · 대소문자를 무시하고 견준다. 못 찾으면 방법마다 무엇을 찾았나를 실패 까닭에 남긴다 |
| 목록 CSV | `pages.csv` — id · 깊이 · 제목 · 경로 |
| 페이지마다 PDF | «받는 방법»(`how`)에 따라 — **export**: `/spaces/flyingpdf/pdfpageexport.action?pageId=…`을 이 브라우저의 로그인으로 받는다(요청 보호를 넘기게 `X-Atlassian-Token: no-check`) · **page**: 페이지를 열어 화면 그대로 PDF로 찍는다(내보내기가 막혀 있을 때 — 느리지만 볼 수 있으면 된다). `pdf/<트리 경로>.pdf`에 · 이미 있으면 건너뛴다 · 거부(4xx) · PDF 아님은 다시 해 보지 않고 서버가 말한 까닭을 남긴 채 그 행만 실패 |
| 결과 CSV | `result.csv` — 페이지마다 ok · 파일 · 실패 까닭 |

실행 입력:
- `rootPath` — 좌측 트리의 경로를 `>`로(기본 `05. 팀 별 공간 > 08. 플랫폼개발 > [서비스파트]`). 끝 제목으로 찾고 앞 제목들이 조상에 있는 것 하나를 고른다
- `spaceKey` — 같은 경로가 여러 스페이스에 있을 때만

결과는 서버의 파일 폴더(`data/files/<워크플로우 uuid>/`)에 남는다 — `pdf/` · `pages.csv` · `result.csv`.
끊기면 다시 돌린다: 받은 PDF는 건너뛰고 남은 것만 받는다.

★로그인 완료는 주소로 본다(`confluence.nexon.com`의 로그인 화면이 아닌 곳) — 다른 Confluence에 쓰면 로그인 노드의 «끝났다는 표시»를 바꾼다.
★제목의 `/`는 폴더가 되지 않게 `_`로 · 파일 이름에 못 쓰는 글자(`: ? *` …)도 `_`로 바꾼다.

## HTML로 + 클론 사이트 — `confluence-html.json` · `site/build.ts`

PDF와 같은 길(로그인 → 페이지 목록 → 목록 CSV)에서, 페이지마다 **열어서 HTML을 뽑고**, 본문의 **그림 · 첨부를 받아**, 끝에 **zip 하나로 묶는다**.
그 zip(을 푼 폴더)으로 **로그인 없이 열리는 정적 사이트**를 짓는다.

```
로그인(사람) → 페이지 목록(REST) → 목록 CSV → 페이지마다 HTML → 그림 · 첨부 목록(REST) → 그림 · 첨부 받기 → 결과 CSV → zip으로 묶기 → 판정
```

| 실행 입력 | 뜻 |
|---|---|
| `area` | `content` 본문만(`#main-content` — 메뉴 · 트리 없이 · 제목은 `<title>`로) · `page` 페이지 전체 |
| `assets` | `all` 본문의 그림과 링크된 첨부 모두 · `images` 그림만(첨부가 크고 많을 때 — 첨부 링크는 위키를 가리킨다) |
| `zipName` | 결과 zip 이름(기본 `confluence-html`) |

결과 zip: `html/<트리 경로>.html` · `assets/<위키 경로>`(첨부 · 썸네일 · 아이콘) · `pages.csv` · `result.csv`. 노드 «zip으로 묶기»의 설정에서 내려받는다.
권한이 없는 페이지는 본문이 없어 그 행만 실패로 남는다. 다시 돌리면 받은 것은 건너뛴다.

### 클론 사이트 만들기

```bash
unzip confluence-html.zip -d 수집
node examples/confluence/site/build.ts 수집 사이트 --zip      # 사이트/index.html을 파일로 바로 연다 · 사이트.zip도
```

- `site/` 폴더만 복사해 어디서든 돌린다 — Flowsmith 저장소가 없어도 된다(Node 24 · 의존 없음): `node 어디든/site/build.ts <수집 폴더> <사이트 폴더>`
- ★**사이트 폴더는 수집 폴더와 다른 곳**이어야 한다 — 같거나 서로 안에 있으면 멈춘다(사이트 폴더를 비우고 새로 쓰기 때문). 비어 있지 않은 폴더는 이 스크립트가 만든 사이트(`.confluence-site` 표시)일 때만 비운다

- 페이지마다 위키 본문을 꺼내 **링크 · 그림을 로컬 경로로** 바꾼다 — `viewpage.action?pageId=` · `/display/<스페이스>/<제목>` · `/spaces/…/pages/<id>` · 첨부 · 썸네일(없으면 원본으로) · 아이콘
- 스크립트 · `on…` 속성 · 위키 스타일시트는 걷어 내고, **왼쪽 트리 · 경로 · 검색(본문까지)** 이 있는 틀과 가벼운 CSS(표 · 코드 · 정보 상자 · 펼치기 · 할 일)를 씌운다 — 서버 없이(file://) 돈다
- 사이트에 없는 위키 주소(받지 않은 페이지 · 위키 기능)와 위키 밖 링크는 원래 주소로 남기고 새 창으로 연다 — 몇 곳인지 알려 준다
- Jira 이슈 목록처럼 그때그때 그려지는 매크로는 수집한 순간의 모습이다
- ★**사내 위키 내용이다 — 만든 사이트는 사내에서만 연다**(외부 호스팅 · 공개 링크에 올리지 않는다)
