# Confluence — 페이지 트리를 PDF로

`confluence-pdf.json` — 사내 Confluence(Data Center)에서 시작 페이지와 그 아래 모든 페이지를 **Confluence의 PDF 내보내기**로 받아, 트리 경로대로 폴더에 저장한다.

```
로그인(사람) → 페이지 목록(REST) → 목록 CSV → 페이지마다 PDF(행마다 반복 · 파일로 저장) → 결과 CSV → 판정
```

| 노드 | 하는 일 |
|---|---|
| 로그인(사람) | 로그인 화면을 열고 **사람이 로그인할 때까지** 기다린다(10분). 실행 화면에서 직접 로그인한다 — 비밀번호는 워크플로우에 두지 않는다 |
| 페이지 목록(REST) | 로그인한 브라우저의 쿠키로 `/rest/api/content/search`(CQL)에서 시작 페이지를 찾고 `/child/page`를 재귀로 돈다. 좌측 트리를 화면에서 펼치지 않는다 — 접힌 가지 · 늦게 그려지는 트리를 놓치지 않게 |
| 목록 CSV | `pages.csv` — id · 깊이 · 제목 · 경로 |
| 페이지마다 PDF | `/spaces/flyingpdf/pdfpageexport.action?pageId=…`을 이 브라우저의 로그인으로 받아 `pdf/<트리 경로>.pdf`에. 이미 있으면 건너뛴다 · 받은 것이 PDF가 아니면(권한 없음 · 로그인 풀림) 그 행만 실패 |
| 결과 CSV | `result.csv` — 페이지마다 ok · 파일 · 실패 까닭 |

실행 입력:
- `rootPath` — 좌측 트리의 경로를 `>`로(기본 `05. 팀 별 공간 > 08. 플랫폼개발 > [서비스파트]`). 끝 제목으로 찾고 앞 제목들이 조상에 있는 것 하나를 고른다
- `spaceKey` — 같은 경로가 여러 스페이스에 있을 때만

결과는 서버의 파일 폴더(`data/files/<워크플로우 uuid>/`)에 남는다 — `pdf/` · `pages.csv` · `result.csv`.
끊기면 다시 돌린다: 받은 PDF는 건너뛰고 남은 것만 받는다.

★로그인 완료는 주소로 본다(`confluence.nexon.com`의 로그인 화면이 아닌 곳) — 다른 Confluence에 쓰면 로그인 노드의 «끝났다는 표시»를 바꾼다.
★제목의 `/`는 폴더가 되지 않게 `_`로 · 파일 이름에 못 쓰는 글자(`: ? *` …)도 `_`로 바꾼다.
